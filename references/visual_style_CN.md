# 视觉规范与配色

## 观察与建议分开

案例中反复出现：白色或很浅的底色；粉、蓝、紫、薄荷绿和浅黄分区；深色标签；有轮廓及少量高光的细胞/器官；用组织、膜与细胞核组织机制；对照图重复对应对象。

下述 HEX、字号、线宽及留白是归纳后制定的**设计建议，不是原图逐像素取色**。用户可覆盖这些参数。程序化值以 `../assets/style_tokens.json` 为准；修改规范时同步该文件。默认值只影响视觉，不包含固定的科学语义。

## 配色组合

每图优先选一套，跨图可共享对象颜色。正文与细标签为 `#243247`，主背景 `#FFFFFF`。表中的主色适合对象、轮廓和大标题，不代表均适合小字或白字反衬。

| ID / 名称 | 使用场景 | 浅色填充 → 对应主色 |
|---|---|---|
| P01 柔和蓝紫（默认） | 机制、临床流程、整套图基础 | 蓝 `#EAF3FA` → `#4E79A7`；紫 `#EEE8F5` → `#8870AC`；青绿 `#E4F2ED` → `#469885` |
| P02 暖冷对照 | 状态、干预前后、策略比较 | 暖粉 `#FBE8E4` → `#B95E64`；冷蓝 `#E8F3FA` → `#4F83B6`；中性紫 `#EEE8F5` → `#8B7AA8` |
| P03 多类柔彩 | 环形总览、分类、研究方向 | 粉 `#F8E2E5` → `#B85D76`；蓝 `#E4F0FA` → `#5683B6`；绿 `#E4F2E8` → `#579681`；黄 `#FBF0CF` → `#AA7C28`；紫 `#ECE5F5` → `#8770A7` |
| P04 清爽蓝绿 | 实验流程、样本分支、验证设计 | 蓝 `#EAF2FC` → `#5479B4`；绿 `#EAF5ED` → `#508A62`；紫 `#F0EAF7` → `#8A6BAB` |

小标题可用深蓝 `#284E78`、深紫 `#5A426F`、深绿 `#285F50`、深红 `#843D49` 或深金 `#705218`。强调色 `#C73D4F` 用于干预或重点，若已作类别色则用轮廓、符号或编号强调，避免一色多义。

背景保持浅而平；细胞和器官允许局部渐变。渐变不穿过文字，也不削弱膜与受体边界。若使用白色标题字，应将标题底色加深并检查对比；浅色面板默认深色文字。不要以红绿作为唯一差别。

## 两种兼容模式

**生物场景模式：**L01–L05优先让组织、细胞与细胞器承担分组。可用单个柔和高光和浅暗部表示形体。血管、膜或组织层提供共同空间参照。

**流程/分类模式：**规则面板、细边框、平整浅色和简化图标。卡片用于阶段、独立分支和读出；不把每个分子与标签单独装框。

两模式可局部组合，仍统一字体、轮廓和光源。降低背景渐变、外发光、投影和荧光色的存在感，保留有助于识别的形体明暗。

## 字体、尺寸、留白

- 英文 Arial/Helvetica；中文思源黑体或 Noto Sans CJK SC，缺失时选择可用且字形完整的无衬线字体。以实际交付平台的字体渲染为准。
- 最终刊载尺寸起点：正文8–10 pt、面板标题11–14 pt、分图字母13–16 pt。多面板缩小后重新检查。期刊或用户有明确要求时按其要求。
- 一种主字体家族；标题半粗体，正文常规。科学名称斜体、上下标与希腊字母按内容规范处理。
- 标签紧邻对象，多数控制在两行内；长解释进图注。环形长标签优先水平短标题或外侧引线，少用大角度旋转。
- 外边距从短边3%–5%、面板间距2%–4%起步。先给关系线和标签留空间，再补插画细节。
- 分区边框0.6–0.9 pt、对象轮廓0.7–1.0 pt、机制线0.9–1.3 pt、主阅读箭头1.3–1.8 pt，均按最终尺寸检查；相对层级比数值本身更重要。

## 对象字典

为当前图组记录 `对象名 | 主色 | 轮廓/核形状 | 所处位置 | 标签写法`，沿用已建立的对象映射。不能无依据把某个颜色永久等同某类细胞。

- 同类细胞复用同一图标；至少用两种线索区分重要类别，如颜色+形状或颜色+核形态。
- 细胞通常保留膜、胞质、核三个层次，仅绘制机制相关细胞器。圆形大核、分枝轮廓、不规则边界可帮助识别，但具体身份仍靠标签。
- 受体与膜对齐，胞内外及核内转录位置依据本图内容确认。单一光源可默认来自左上。
- 避免无目的地混用照片质感、玻璃球、强3D和扁平符号。确需材料结构或真实显微图时，用边界和标签区分子图，并协调色彩。
- 图例只列需要重复识别的对象；避免把所有已有局部标注再抄一遍。

## 关系线的语义

| 关系 | 默认表示 |
|---|---|
| 已由材料支持的激活/过程 | 实线箭头；图注区分生物作用和流程顺序 |
| 抑制 | T形端线，终点落到被抑制对象 |
| 分类/归属 | 无箭头分支、括号或分区 |
| 相关性 | 无方向连线并标注 association，除非材料支持方向 |
| 待验证关系 | 虚线并明确标 proposed/hypothesized |
| 放大 | 放大范围轮廓+引线，不混作机制箭头 |

若虚线另用于间接作用，应添加明确标签或另一种线型，不能让同一种虚线无说明地表达多种含义。密集连线先重排布局或拆图；机制线不默认使用淡入渐变。

## 绘图指令的可复用骨架

将实际内容填入以下字段，删除不适用项，而非把占位符留到交付物中：

```text
核心信息：...
内容来源/已确认关系：...
主模板：Lxx；阅读顺序：...
辅助模块：局部放大/图例/结构标注/无
配色：Pxx；正文#243247，浅色分区，少量强调
主要对象与一致性：...
视觉模式：医学插画场景/矢量流程/局部混合
文字语言与必须准确的标签：...
线条含义：...
最终尺寸与交付格式：...
```

给图像生成工具时描述构图、对象位置及风格，不把参考图中的未知机制作为内容来源。密集文字优先后置为精确标注；生成后仍逐一检查受体、连线与文字。只用当前实际可用的工具，不暗示已连接某个第三方绘图平台。
